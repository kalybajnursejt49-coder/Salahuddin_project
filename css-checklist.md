## Классы, ID и исключения в HTML

Повторяемые классы: site-header, site-nav, page-layout, site-footer, content-panel, poster,
page-intro, form-panel, trial-form, choice-field, practice-note, back-to-top.
ID top встречается один раз на каждой странице и используется ссылкой возврата.
about-club, enrollment-section и prices отмечают уникальные блоки; причины выбора ID объяснены в CSS.

- Единственный внутренний style: index.html:13.
- Уникальный ID: index.html:38.
- Единственный inline style: index.html:77.
- Уникальный ID: services.html:54.
- Уникальный ID: pricing.html:33.

Сначала подключён base.css, затем файл участника. Правила одного веса разрешаются порядком записи.
Internal и inline демонстрируют изменение одного фона. В личных файлах ID выигрывает у класса.
Деклараций !important нет: разрешённое исключение не потребовалось.
Новых div, страниц, JavaScript, библиотек, @import и media queries нет.
