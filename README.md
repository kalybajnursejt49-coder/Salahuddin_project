## Формы

Формы учебные: серверного обработчика нет, заявки не сохраняются и не доходят до академии.
Submit проверяет поля и пытается выполнить POST на HTML-файл. Reset возвращает начальные значения.

## CSS

- css/base.css — общие цвета, шрифты, шапка, меню, формы и футер.
- css/nurseyit.css — главная, направления и контакты.
- css/damir.css — тренеры, расписание и цены.

На каждой странице сначала загружается base.css, затем личный файл.
Дизайн рассчитан на обычное окно компьютера: колонка 1080px, светлый фон, тёмный текст,
приглушённый золотой акцент. Media queries пока не используются по условию задания.
Главная и карточки тренеров используют Grid, меню и группы элементов — Flexbox.
Комментарии в CSS объясняют селекторы, позиционирование и приоритеты.
На главной ровно один внутренний style и один inline style для демонстрации каскада.
